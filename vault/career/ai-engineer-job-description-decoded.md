# AI Engineer Job Description Decoded

Read 30 postings and tallied what actually repeats. The results reordered my
whole plan.

Nearly every posting:
- Python, SQL
- One deep learning framework, almost always PyTorch
- APIs, Docker, some cloud
- "Communicates with non-technical stakeholders"

Common, and I underweighted them:
- Classical ML and evaluation - far more than expected
- Data pipelines and cleaning
- LLM/RAG experience, now near-universal

Rare, and I overweighted them:
- Research publications
- Training foundation models from scratch

Conclusion: this is a **software engineering job with ML in it**, not a research
job. [[Month 5 - MLOps]] exists because of this note.
