# Supervised vs Unsupervised

**Supervised** - labelled data, learn input to output. Classification and
regression. Almost everything commercial.

**Unsupervised** - no labels, find structure. Clustering, dimensionality
reduction, and the pretraining behind [[What an LLM Actually Does]].

**Self-supervised** - the trick that made modern LLMs possible: manufacture
labels from the data itself by hiding part of it and predicting it. Unlimited
training data at no annotation cost.

That last one is the conceptual bridge between classical ML and everything in
[[Month 4 - LLMs and RAG]].
