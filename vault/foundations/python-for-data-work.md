# Python for Data Work

I can write Python. I could not write *data* Python, which is a different
dialect.

- List comprehensions and generators over loops
- Dataclasses for anything with structure
- Type hints - not for the interpreter, for the reader
- pathlib over string paths
- A virtual environment per project, always

The habit that matters most: write the function before the notebook cell. Code
that lives only in a notebook cannot be tested, deployed, or reviewed.
