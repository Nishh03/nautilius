# Linear Algebra for ML

The 20% that covers 80% of ML reading.

A **vector** is a point or a direction. A **matrix** is a function that moves
vectors around - rotate, stretch, project. Matrix multiplication is applying
that function.

A **dot product** measures alignment: large when two vectors point the same way,
zero when perpendicular. This one idea reappears as attention scores in
[[Transformers Explained]] and as cosine similarity in
[[Vector Embeddings and Similarity]].

Everything a neural network does is: multiply by a matrix, bend the result,
repeat. See [[Neural Network Basics]].
