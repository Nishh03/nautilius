December 2026. The centrepiece. Closest to what an AI engineer is actually paid
to build.

A question-answering system over a document collection, with cited sources.

Plan:

- Cite sources on every answer, per [[LLM Hallucination]]
- Build the evaluation set *first*, per [[Evaluating LLM Outputs]]

Interview value: I can talk about retrieval quality, chunking, and grounding
from having hit the problems, not from having read about them.
