# Portfolio Strategy

Four projects, each proving a different thing. Fewer, deeper, finished.

1. [[Project 1 - Churn Predictor]] - tabular ML end to end
2. [[Project 2 - Image Classifier]] - deep learning
3. [[Project 3 - RAG Assistant]] - LLM engineering
4. [[Project 4 - Fine-tuned Small Model]] - training, not just calling an API

Every one must have: a live URL, a README explaining the *decisions* not the
steps, a Dockerfile, and honest limitations.

What kills student portfolios: five Kaggle notebooks with no deployment and no
writeup. The notebook proves you can follow a tutorial. The deployment proves
you can engineer.
