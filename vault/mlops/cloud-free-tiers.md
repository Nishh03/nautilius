# Cloud Free Tiers

Deploying the portfolio without paying anything.

- **Hugging Face Spaces** - best fit for ML demos, free GPU-less tier, Docker
  supported
- **Render / Railway** - free web services, they sleep when idle
- **Fly.io** - small free allowance, real containers
- **GitHub Actions** - free CI minutes, also usable as a free scheduler
- **Google Colab** - free training compute, session limits

Sleeping free tiers mean a cold start on the first request. Worth a note on the
project page so a recruiter does not think it is broken.
