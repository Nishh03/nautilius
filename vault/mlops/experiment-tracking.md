# Experiment Tracking

After twenty runs, nobody remembers which hyperparameters produced the good
number. A spreadsheet works until it does not.

Track per run: parameters, metrics, the data version, the git commit, and the
artefact.

MLflow runs locally and free, which is enough for a portfolio. Weights and
Biases has a free tier and better visuals.

The point is not the tool. It is that an untracked good result is not a result,
because it cannot be reproduced or defended in an interview.
