# Literature Review Notes

Five sources, each read as contribution plus limitation:
Obsidian proved plain linked markdown lasts, but notes stay passive.
Forte proved organizing is the bottleneck, but it is a habit not a tool.
RAG proved grounding works, but assumes heavy infrastructure.
Notion AI proved the demand exists, but rents you the AI layer.
Agentic scheduling proves self-maintenance is practical, but needs supervision.
